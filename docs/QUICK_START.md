# Quick Start Guide for Coder Server

This guide will help you get started with running the Coder server locally.

## Prerequisites

- Ensure you have Git Bash installed.
- Make sure you have the `coder.exe` file in the project root directory.

## Starting the Coder Server

1. Open Git Bash.
2. Navigate to the project directory:
   ```bash
   cd /c/path/to/your/local/coder/
   ```
3. Run the start script:
   ```bash
   ./start.sh
   ```

4. Once the server is running, open your browser and go to `http://127.0.0.1:3000`.

## Stopping the Coder Server

To stop the server, press `Ctrl+C` in the terminal where the server is running.

## Troubleshooting

- If you encounter any issues, ensure that the `coder.exe` file is present in the project root directory.
- Make sure you have the necessary permissions to execute the script.

For more detailed documentation, refer to the [official Coder documentation](https://coder.com/docs).
